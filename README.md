This Python script analyses T-cell receptor (TCR) clonotypes from single-cell V(D)J sequencing data. It processes the TRA (TCR alpha) and TRB (TCR beta) chains, assigns clonotype IDs, identifies cells with multiple chain combinations, and attempts to resolve ambiguous clonotype assignments.
